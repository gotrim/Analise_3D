## Sobre o projeto

Analise 3D é um laboratório interativo de geometria feito com HTML, CSS e JavaScript puro. A cena é desenhada no Canvas 2D usando vértices, faces, rotações nos eixos X e Y e projeção em perspectiva.

## Funcionalidades

- Seleção entre cubo, pirâmide e prisma pentagonal
- Rotação automática e controles manuais nos eixos X e Y
- ViewCube com seis vistas para orientar a cena
- Criação de formas livres marcando pontos em várias vistas, com profundidade ajustável
- Formas criadas ficam salvas no navegador e podem ser apagadas
- Alternância independente de faces, arestas, vértices e eixos
- Controle deslizante para ajustar a distância da câmera
- Leituras dos ângulos de rotação e da distância
- Layout responsivo e atalhos de teclado

## Como usar

Abra `index.html` em um navegador. Não há dependências ou etapa de compilação.

- Setas: girar a forma
- Espaço: pausar ou retomar a animação
- R: redefinir a cena

Para criar uma forma, selecione **Criar forma livre...**, use o ViewCube ou as setas para mudar a vista e marque pelo menos três pontos no palco. Ajuste a espessura e selecione **Criar forma 3D**. **Apagar ponto** desfaz o último ponto; **Excluir** remove a forma salva selecionada.
